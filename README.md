# 🩺 Lab Report Checker (RC)

A simple and user-friendly Android application designed to help users understand their medical lab reports. It compares inputted test results against standard reference ranges and provides an instant analysis of whether the values are Normal, High, or Low.

## ✨ Features

*   **Single & Package Tests:** Check individual tests or a full profile.
*   **Dynamic Reference Ranges:** Provides ranges based on Gender and Age (Adult/Child).
*   **Multiple Units:** Supports unit conversion (e.g., mg/dL to mmol/L) for better accuracy.
*   **Instant Analysis:** Automatically categorizes results as Normal, Low, High, or Borderline.
*   **Categorized Tests:** Organized into Hematology, KFT, LFT, Lipid Profile, Hormones, ICT/Kit Tests, etc.
*   **Offline Support:** All data is stored locally within the app.

## 🛠️ Built With

*   [Kotlin](https://kotlinlang.org/) - The programming language used.
*   [Android Studio](https://developer.android.com/studio) / AndroidIDE - The IDE used for development.

## 📥 How to Download and Install

1. Go to the **Releases** section on the right side of this page.
2. Download the latest `.apk` file (e.g., `LabReportChecker-release-signed.apk`).
3. Open the downloaded file on your Android phone.
4. If prompted, allow your browser or file manager to **"Install unknown apps"**.
5. Click **Install** and open the app.
